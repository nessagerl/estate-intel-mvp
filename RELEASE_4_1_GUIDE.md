# Release 4.1 — Exploration UI

Based on Release 4 hydration-fix ZIP.

## Changes
- Add Photo control remains available at top, within AI findings, after findings, and in a sticky bottom action on mobile.
- Same photo input is reused throughout, preserving existing same-item/different-item comparison flow.
- AI findings displayed in separate readable cards with headings, rather than one large block.
- The server currently enforces a maximum of 12 photos per exploration; this release does not change that safeguard.

## Installation
1. Back up your existing project; preserve `.env.local`.
2. Copy contents of `estate-intelligence-release-4` into the project.
3. No Supabase migration required. Do not rerun previous SQL.
4. Stop development server. Run `npm run build` and `npm run dev`.
5. Test photos 1, 2, 3, and 4, including the different-item confirmation and saved investigation continuation.

## Notes
This is a UI-focused patch. AI analysis still returns plain text; cards are generated by parsing recognized section headings. A future structured JSON response would offer stronger formatting guarantees.
